Grain 通过一个很小的 JSON API 接收评论，先扣住不发，等你回复一封邮件批准，再把通过的评论发布成站点旁边的静态 JSON 文件。你的博客保持纯静态；审核就在收件箱里完成。

做它的原因很简单：我想在这个站点上有评论，但不想有一个第三方脚本盯着我的读者。
